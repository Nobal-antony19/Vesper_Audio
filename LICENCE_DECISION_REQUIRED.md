# Licence decision required before publishing source

No licence has been added automatically because selecting an open-source licence grants
permissions to other people and should be an explicit decision by the copyright holder.

Choose one after reviewing all original code, copied code, generated code and third-party
dependencies/notices:

- **GPL-3.0-only** — strong copyleft; derivatives distributed under GPL-3.0.
- **GPL-3.0-or-later** — strong copyleft with permission to use a later GPL version.
- **MPL-2.0** — file-level copyleft, allowing larger works to combine differently licensed files.
- **Apache-2.0** — permissive, includes an express patent grant.

Do not copy Auxio or another project's source unless you comply with its actual licence and
preserve required notices. General ideas and independently written implementations are not
the same as copying source.

Before adding `LICENSE`, audit dependency licences and third-party assets. This document is
not itself a software licence.
